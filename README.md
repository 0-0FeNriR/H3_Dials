# H3 Dials

Приложение для оформления приборной панели Haval H3 на совместимом штатном ГУ. Независимый проект, не является официальным ПО Haval/GWM.

## Скачать

Готовые APK находятся в [Releases](https://github.com/0-0FeNriR/H3-Dials/releases). Здесь публикуются только выпуски и инструкции. Исходники хранятся отдельно и закрыты.

## Установка с Windows

1. Автомобиль неподвижен, ГУ включено. Включите ADB и подключите ноутбук USB-кабелем с передачей данных. Подтвердите запрос отладки на ГУ.
2. Установите Android SDK Platform-Tools. В PowerShell (путь к ADB замените своим):

```powershell
$adb = 'C:\ADB\platform-tools\adb.exe'
& $adb devices -l
& $adb install -r 'C:\ADB\H3-Dials-1.0.apk'
& $adb shell pm grant dev.h3.dials android.permission.READ_PHONE_STATE
& $adb shell am start -n dev.h3.dials/.MainActivity
```

3. В приложении включите панель и при желании автозапуск. Выберите штатный тахометр и выполните «Синхронизацию меню».

READ_PHONE_STATE используется для сворачивания тахометра при звонке. На исследованной прошивке доступ к чтению автомобильных данных выдаётся автоматически. Root и специальные возможности не требуются. Совместимость с другими прошивками не гарантируется.

При совпадающем сертификате и большем внутреннем номере `install -r` сохраняет настройки. При ошибке подписи не удаляйте приложение без понимания потери настроек.
